# ChuChu-Theme: Clawd on Desk theme

ChuChu is a golden ginger cat with soft tabby markings, yellow-green eyes, a pink nose and a large fluffy tail.

- 40 transparent animated PNGs (APNG) in `assets/`, with 32 frames each
- 135 × 135 px, which is 3× Clawd's 45-unit square canvas
- The cat sits in the middle-lower part of the canvas, with its feet about 5% above the bottom edge
- `theme.json` maps every Clawd state, reaction, working tier, idle animation, update animation and mini-mode animation

Install instructions are in the repository's top-level `README.md`.
